# How to Download and Install VirtualBox
### Project Walk-through:
_You may notice that the wizard prompt it says version 5.2.22 while the download version says 7.1.8. I forgot to take screenshots during the installation so I had to get images from the web. It is still the same process!_ </br>
</br>1. First, open your preferred Web Browser and navigate to https://www.google.com. </br>

![Image](https://github.com/user-attachments/assets/19e4b30e-6ea8-41c1-976c-dade0d130391)

2. Once in Google.com search for VirtualBox download and press Enter.

![Image](https://github.com/user-attachments/assets/3917192a-2f57-4dab-93e0-d2b9e25e6897)

3. From the search results select the Downloads - Oracle VM VirtualBox link that reads https://www.virtualbox.org/wiki/Downloads.

![Image](https://github.com/user-attachments/assets/55ece493-1588-4acb-b324-2b816a7d2ed2)

4. Choose from the download section VirtualBox for your OS platform. In my case, we are selecting Windows because that’s what I use for my Host Base OS.

![Image](https://github.com/user-attachments/assets/d93df26f-9ac2-47fa-ab32-fa1da789873c)

5. The download will start and when the download is complete we are going to launch the installation. Click on the Next button to start the wizard.

![Image](https://github.com/user-attachments/assets/b51d1a5f-6330-41bb-bac9-be6946acf6c7)

We can leave all these settings at default. There’s no reason for us to change any of these settings so we just click Next. If at any point during the installation you are prompted to install devices you need to make sure that you choose Yes to install them, that way you won’t have any issues while you are trying to use VirtualBox.

![Image](https://github.com/user-attachments/assets/b1ed30d1-399b-4a5b-9d58-e6397825b0b8)

6. Now, it has launched Oracle VM VirtualBox. And that’s all we have to do to download and install VirtualBox.

![Image](https://github.com/user-attachments/assets/15eb5eec-d442-4a3e-aac6-cb1ee6fb0bd6)
