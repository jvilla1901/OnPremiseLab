# OnPremiseLab
### Description:
In this lab, I will show you how to create a virtual machine by downloading and installing VirtualBox, creating a Virtual Network, creating and modifying Virtual machines, and installing an OS on the Virtual Machine. The OS that we will be using is Windows Server 2016. Before we get started, it is crucial that your device can run VirtualBox. The requirements are: a quad-core CPU or more, a minimum of 8 GB of RAM, a 64-bit OS, and ensure the virtualization technology is enabled in your motherboard’s BIOS.
